## Benchmarking models for computing Target Strength (TS) of solid sphere and solid shell objects
- The two Comsol models here are set to compute the scattered acoustic fields from 1) a solid sphere and 2) a solid shell with fluids inside and outside the shell.
- Solid sphere model: Model file `solid_sphere_scattering_20220919.mph` contains computed results using a solid sphere with a 3 cm radius. The solid sphere has material properties of Copper (cp=4760 m/s, cs=2288.5 m/s).
- Solid shell model: Model file `solid_shell_scattering_20220923.mph` contains computed results using a solid shell with the outer radius of 3 cm and inner radius of 2.5 cm. The solid shell has material properties of WC (cp=6853 m/s, cs=4171 m/s), and the inner/outer fluid as water.
