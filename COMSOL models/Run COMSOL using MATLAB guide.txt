In COMSOL GUI

1. Clear previous solver and job configurations, remove any result/plot nodes
2. Compact History
3. Save as MATLAB script

In MATLAB script

1. Line 1: function out = TS_rigid_sphere %change this depending on your model
2. Line 12: specify the correct directory where you will run the model. pwd works as well.
3. Insert this piece of code before the last line 'out = model'

model.study('std1').run;

resultsDir = fullfile(pwd, 'results');
if ~exist(resultsDir, 'dir')
    mkdir(resultsDir);
end
mphsave(model, fullfile(resultsDir, 'TS_rigid_sphere_output.mph')); %change this depending on your model


This code runs the model, creates a results sub-directory, and saves the output mph file
